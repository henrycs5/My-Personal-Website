Computer Science Experience

AP Computer Science A

Nearing noon of Wednesday, May 7th, 2025, I was sitting in my seat filled with nervousness. This was my first AP class that I have ever taken. The content itself wasn't so bad; I was often going ahead in the class so can I allocate more time to Math 124, Pre-Calculus. Nonetheless my experience in this course taught me the foundations of Java and onward. Other than the AP exam I completed two projects: Hangman and a simple bossfight featuring the Block Tales boss Hatred. Contary to my Hangman game which only included text, the bossfight required me to learn Java GUI which was not a fun topic to learn. I had all these ideas but I wasn't skilled nor did I have enough time to implement them. I eventually settled on having two buttons that either damages the boss or is an instant game over. The buttons spawn on very fast intervals, if you don't click the attack button you get damaged. Whether you win or lose you can get special title screens!

Roblox Studio

Roblox was the reason why I wanted to pursue computer science. More specifically, to create fun and cultivating games for people to play. In fact this is the game icon for my first Roblox game. It didn't have much functionality besides free models that I got from the toolbox. Eventually, after taking a long break from Roblox Studio, I started to learn Lua which was Roblox's coding language. Despite losing motivation at times I'm proud of using the things I learned from YouTube tutorials and applying them to create some awesome stuff. I hope in the future I can create the games of my dreams!

Unity

Game Programming was given to me as a special case. I was in my teacher's 6th period Web Design class but worked independantly. The challenge was to learn Unity's tutorials at my own pace. I created a Boss Rush game which was an FPS with mobility movement like dashes. It was an application of everything I learned from Unity with outside research on certain features. Although I never finished the game, I was a big help to my teacher in shaping the class as well as being a great example for future students to look up to.
